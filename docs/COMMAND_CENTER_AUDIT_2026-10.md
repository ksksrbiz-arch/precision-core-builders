# Command Center audit — October 21, 2026

Scope: `/admin` dashboard, its lead board, realtime updates, and the project/ledger queries supplying its metrics. This is a source and local-runtime audit, not verification of the deployed site or live Supabase data.

| Finding                                                                                                                                          | Result                                                                                                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Project or ledger query errors became empty data/zero costs, potentially showing a new-workspace welcome or an inflated margin during an outage. | Metric repository queries now propagate failures to the dashboard's error state. The single-project cost reader follows the same rule.                                                                       |
| Recent projects, recent reports, material shortages, weekly activity, and the lead board could fail silently.                                    | Each failed query has a visible error and a retry that targets that query. Failed metrics no longer say “No data yet.”                                                                                       |
| A failed AI scoring request appeared as a real score of zero with low priority.                                                                  | Failure is a separate alert; no score or board entry is fabricated. Rate limits remain distinguishable even when the response body is not JSON.                                                              |
| A malformed HTTP 200 response could crash the score display or be sent to persistence.                                                           | Validate the response shape, score range, priority, and value before rendering or saving.                                                                                                                    |
| Saving a successfully scored lead failed silently. Input accepted by scoring could also exceed the board's project-type limit.                   | Keep the result visible and flag an unsuccessful save. Input length limits fit both endpoints; whitespace-only names cannot submit.                                                                          |
| Lead-board reads were not gated by authentication readiness.                                                                                     | Gate them with the same admin readiness check as other dashboard queries.                                                                                                                                    |
| Navigating away during scoring could still trigger a late save; realtime flashes left overlapping timers.                                        | Abort pending score requests on unmount and discard late responses. Reset the flash timer per event and clear it on unmount. Project updates also invalidate recent reports so joined project names refresh. |
| The budget chart rounded $250 to a zero-height bar.                                                                                              | Preserve fractional thousands and format tooltip values as currency.                                                                                                                                         |
| “Clear all” described only the displayed count although deletion affects the whole board.                                                        | Confirmation explicitly includes saved leads beyond the 50 shown. Destructive controls disable while their mutations are pending.                                                                            |
| “Total Projects” said “All time” although archived projects are excluded.                                                                        | Label its scope as unarchived projects.                                                                                                                                                                      |
